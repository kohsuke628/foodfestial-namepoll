# 🕒 スケジュール調整 Webアプリ（時間割単位）

複数人の空き時間を「時間割 (1限、2限…)」単位で集計・把握できる、GitHub Pages 対応の完全静的Webアプリケーションです。

---

## 🛠️ 1. Firebase プロジェクトの作成と設定

ビルド不要で動作させるため、Firebase の Firestore と Authentication を利用します。

### ステップ 1: Firebase プロジェクトの作成
1. [Firebase Console](https://console.firebase.google.com/) にログインし、「プロジェクトを追加」をクリックします。
2. プロジェクト名（例: `schedule-app`）を入力し、指示に従って作成します（Google アナリティクスはオフで問題ありません）。

### ステップ 2: Authentication (メール+パスワード) の有効化
1. 左メニューの **「構築」 > 「Authentication」** を開きます。
2. 「始める」をクリックし、**「メール/パスワード」** を選択して有効化・保存します。
3. **「Users」** タブに移動し、「ユーザーを追加」から管理者用の **メールアドレスとパスワード** を手動登録します。

### ステップ 3: Cloud Firestore の作成
1. 左メニューの **「構築」 > 「Firestore Database」** を開きます。
2. 「データベースの作成」をクリックします。
3. データベースのロケーションに **`asia-northeast1` (Tokyo)** を選択し、「テストモードで開始」で作成します。

### ステップ 4: セキュリティルールのデプロイ
1. Firestore の **「ルール」** タブを開きます。
2. リポジトリ内の `firestore.rules` の内容をすべて貼り付けて「公開」をクリックします。

### ステップ 5: Web App 設定値の取得と反映
1. プロジェクト設定（歯車アイコン） > **「全般」** タブを開きます。
2. 「マイアプリ」で Web アプリ（`</>` アイコン）を追加登録します。
3. 表示された `const firebaseConfig = { ... };` の設定値をコピーします。
4. プロジェクト内の `firebase-config.js` を開き、値を書き換えて保存します。

## 🚀 2. GitHub Pages への公開手順

1. GitHub で新規リポジトリを作成します（例: `schedule-adjuster`）。
2. 本プロジェクトのファイル群（`index.html`, `style.css`, `app.js`, `firebase-config.js`, `firestore.rules`, `README.md`）をプッシュします。
3. リポジトリの **Settings > Pages** を開きます。
4. **Build and deployment** の Source で `Deploy from a branch` を選択します。
5. Branch を `main` (または `master`) の `/ (root)` に設定し、**Save** をクリックします。
6. 数分後、発行された URL（`https://<username>.github.io/<repository-name>/`）でアクセス可能になります。

## 🧪 3. 動作確認の手順

1. **管理者ログインとアンケート作成**
   - 発行された URL にアクセスし、右上（または URL 末尾 `#/admin`）から管理者ログイン画面へ移動します。
   - Firebase Authentication で登録したメールアドレスとパスワードでログインします。
   - 「+ 新規作成」を押し、タイトル・日付範囲・時間割コマ・期限・上限人数を入力して「作成して回答URLを取得」をクリックします。
   - 生成された回答用 URL（`#/s/xxx...`）をコピーします。

2. **回答者として入力（スマホ推奨）**
   - 別ブラウザ（またはシークレットウィンドウ）でコピーした回答用 URL を開きます。
   - 名前と学生番号を入力し、時間割グリッドの空いているコマをタップして選択します。
   - 備考（「〇〇日は遅刻します」など）を追加して「回答を送信する」をクリックします。

3. **回答の修正確認**
   - 再度同じ回答URLを開きます。同じ名前と学生番号（または自動読み込み）により、前回入力したデータが復元されていることを確認し、変更して再送信します。

4. **管理画面での集計確認**
   - 管理者画面（`#/admin`）に戻り、作成したアンケートの「回答確認」をクリックします。
   - **ビューA (人 × 時間割)**: 回答者の空きセルが色付けされ、最下行にヒートマップが表示されていることを確認します。セルをクリックするとそのコマの参加者一覧モーダルが開きます。
   - **ビューB (連続可能時間)**: 連続したコマが「10:10〜14:00」のように自動サマリーされていることを確認します。
   - 「CSVダウンロード」を押し、Excelで文字化けせず出力されることを確認します。
